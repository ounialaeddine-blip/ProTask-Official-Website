ProTask icons

56 icons drawn from the CdC identity: one for each function, smart indicator and AI feature. Click a tile or an outline icon to copy its code.

Tile, as an image

Ready-made colored tile. Works everywhere, even when you double-click the HTML file.

Outline, from the sprite

Takes the text color of its parent. Needs a local server such as VS Code Live Server.

</svg>

Outline, as an image

One file per icon, always Deep Navy. Use it when the color does not need to change.

<img src="icons/svg/kanban.svg"
     alt="" width="24" height="24">
  • One grid24 px grid, 1.75 px line, rounded ends, so every icon has the same weight.
  • One signatureA single mint dot in each icon, like the dot in the ProTask logo.
  • Color by roleBlue for work, navy for people and security, soft blue for data, mint for AI, slate for version 2.
  • ReadableTile colors keep at least 4.5:1 contrast between glyph and background. Add a text label next to an icon whenever the meaning is not obvious.
